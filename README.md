## Built with

- HTML5, CSS3, and JavaScript
- Font Awesome and Simple Icons
- Typed.js and ScrollReveal

## Run locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Nandhi005/Nandhees_Portfolio.git
   cd Nandhees_Portfolio
   ```
2. Open `index.html` in your browser, or serve this folder with a local static web server.
3. Edit `index.html`, `Style/styles.css`, and `JS/main.js` as needed.

No build step is required for this static site.

## Deployment

The site is published with GitHub Pages from this repository. Push committed changes to the configured publishing branch to update the live site.
